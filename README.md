# 🖼️ Photo Shrinker — Offline Visually-Lossless Batch Compressor

A fast, privacy-first, single-file web app for batch-compressing JPG photos at visually lossless quality. Your originals are never touched, and nothing ever leaves your device.

🔗 **Live App:** [https://swarnim0308.github.io/photo-compressor/](https://swarnim0308.github.io/photo-compressor/)

---

## ✨ Features

- **100% Private & Local Processing:** Zero server uploads. All compression runs directly inside your browser on Windows, Mac, Android, or iOS.
- **Visually Lossless Compression:** Uses a calibrated `0.82` quality target to shrink file sizes by **60%–80%** while preserving crisp detail.
- **Interactive Before / After Inspector:** Compare the original and compressed versions of your first photo side-by-side with a draggable slider, panning, and **Fit, 2×, 4×, and 8× zoom** controls.
- **Flexible Batch & Folder Input:** Drag and drop entire folders or select multiple files at once (`JPG`, `PNG`, `WebP`, plus automatic passthrough copying for `HEIC` files).
- **Smart Controls:**
  - **Max Size (Longest Edge):** Choose between `2560 px (recommended)`, `Original size`, `3840 px (4K)`, or `1920 px` (photos are never enlarged).
  - **EXIF Metadata Toggle:** Keep or strip camera details, date taken, and GPS coordinates.
- **One-Click ZIP Export:** Download all compressed photos bundled cleanly in a single `.zip` archive alongside a live progress counter and total space-saved tracker.

---

## 📱 How to Use on Android

1. Open [Photo Shrinker](https://swarnim0308.github.io/photo-compressor/) in **Google Chrome**.
2. Tap the **three-dots menu (`⋮`)** → **Add to Home screen** to install it like a native app.
3. Tap **Choose photos** and select **Files** or **Documents** in the system picker to batch-select hundreds of photos at once.

---

## 💻 How to Use on Windows / Desktop

1. Open [Photo Shrinker](https://swarnim0308.github.io/photo-compressor/).
2. Click **Choose folder** (or drag and drop photos directly onto the drop zone).
3. Verify quality using the **2×–8× zoom comparison slider**, then click **Download all as ZIP**.
